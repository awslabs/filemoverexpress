FME — OIDC Sign-in UX (proposed)

Sign-in lives in the empty file panel (where it appears the moment you pick an OIDC config — impossible to miss, zero toolbar crowding). The browser-launch / waiting / cancel / errors happen in a modal. Once signed in, the toolbar shows only a small “Signed in” chip.

State 1 — OIDC config selected, not signed in

Toolbar is clean (no sprawling status). The panel itself invites sign-in.
