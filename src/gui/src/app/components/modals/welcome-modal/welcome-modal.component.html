File Mover Express

Welcome to File Mover Express. In this application, you can transfer files and folders by dragging and dropping between your Local file system and your S3 bucket. You can use the Jobs tab to monitor your jobs, the Logs tab for more information, and the Bucket Reports tab to track the bucket reports you’ve generated.

To get started, select the “Create a Remote Configuration” button. If you have already configured your settings, you can immediately begin transferring files or explore other features to manage your data.
