# Agent Workspace

This folder is a scratch area for AI coding agents (Kiro, Claude, Cursor, etc.)
working in this repository.

**Everything in this folder is git-ignored** except this README. Agents put
their temporary notes, planning docs, investigation write-ups, build logs, and
any other throwaway working files here so they never get accidentally committed
to the project.

If you are a human browsing the repo: nothing of record lives here. Anything an
agent needs to keep belongs in real project files (source, `docs/`, a PR
description, or an issue), not here.

See `AGENT.md` at the repo root for the full policy.
