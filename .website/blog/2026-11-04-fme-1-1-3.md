File Mover Express 1.1.3 adds transfer notifications to your chat tools and
turns adaptive concurrency on by default, so strong throughput is the
out-of-the-box behavior.

<!-- truncate -->

## Transfer notifications

- **Get notified when a job finishes** through Slack, Microsoft Teams, Discord,
  Google Chat, or any custom webhook. The message includes the job name,
  destination, file count, total size, and transfer speed.
- Presets are provided for each service, so setup is a matter of pasting in the
  webhook URL. A global option can notify on every transfer, including hot-folder
  and CLI-driven jobs.
- Webhook URLs are stored encrypted, and the sender is guarded against sending
  to internal or private network addresses.

## Adaptive concurrency is now on by default

- **Adaptive concurrency** (introduced as opt-in in 1.1.2) is now enabled by
  default. FME automatically tunes how many parallel connections it uses for the
  shape of your transfer, so you get strong throughput without hand-tuning.
- It remains fully opt-out if you prefer to set your own concurrency.
