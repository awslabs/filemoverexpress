The first public release of File Mover Express: a high-performance,
open-source app for moving media between local storage and Amazon S3, with a
desktop GUI, a full CLI, and an MCP server for AI assistants.

<!-- truncate -->

## High-performance S3 transfers

- Auto-tuned parallel transfers using native S3 APIs, with no intermediary
  servers.
- Multipart upload and download with configurable chunk sizes and retry on
  failure.
- Pause, resume, and cancel active transfers.
- Transfer priority scheduling and job queue management.

## Desktop application

- Native desktop app for macOS (Apple Silicon and Intel) and Windows (x64 and
  arm64).
- Drag-and-drop file management between the local filesystem and S3.
- Real-time transfer progress, speed, and ETA display.
- File browser for both local and S3 with search and filtering.

## Hot folders

- Monitor local directories for new files and automatically upload them to S3.
- Configurable inclusion/exclusion filters and deduplication.

## Checksums and media integrity

- XXH3, XXHash64, XXHash, and MD5 checksum algorithms.
- MHL (Media Hash List) support for camera-to-cloud verification workflows.
- Post-transfer integrity verification.

## Remote daemon architecture

- Run the transfer engine on any machine (workstation, server, or EC2
  instance).
- Control it remotely from the GUI or CLI over an encrypted ConnectRPC
  connection.
- Transfer profiles for managing multiple daemon connections.

## Command-line interface

- Full CLI for scripting, automation, and headless environments.
- All GUI features accessible from the command line.
- Scriptable job control (start, pause, resume, cancel).

## MCP server (fme-mcp)

- A standalone [Model Context Protocol](https://modelcontextprotocol.io/)
  server for AI-assisted file transfers.
- Nine tools: connect, browse local/S3, start upload/download, pause, resume,
  cancel, and list jobs.
- Supports stdio and streamable-http transports, so AI coding assistants can
  manage S3 transfers directly.

## Cross-platform

- macOS: Apple Silicon (arm64) and Intel (x64).
- Windows: x64 and arm64.
- Linux: x64 and arm64 (build from source, or use the CLI/MCP binaries).

Download the build for your platform from the
